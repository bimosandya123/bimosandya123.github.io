Privacy Policy

Last updated: 20 October 2026

This policy covers the personal automation tool run by Bimo Sandya Prima Sakti. The tool is used only by its owner and only with the owner's own Google account.

What data it uses

  • Gmail (read-only): it reads job-related emails, such as application confirmations and recruiter replies, to sort them and send a short alert. It never sends, deletes or changes emails.
  • Google Sheets: it writes job application details to the owner's own job tracker sheet.

How data is handled

  • Email content is processed to create short summaries, which may use an AI service (Google Gemini) for that purpose only.
  • Alerts go only to the owner's own Telegram chat.
  • No data is sold, shared with third parties for advertising, or used for any other purpose.
  • Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
